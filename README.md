# Social App — Backend

API de una aplicación social desarrollada con **Node.js, Express y MongoDB**. Complementa el frontend en React.

## Tecnologías
- Node.js y Express
- MongoDB y Mongoose
- Socket.IO
- bcrypt y validación de datos
- SDK de Mercado Pago

## Organización
El código está organizado en `src/controllers`, `src/models`, `src/routes`, `src/middlewares` y `src/sockets.js`.

## Ejecutar localmente
```bash
npm install
npm run dev
```

El proyecto puede requerir servicios externos y variables de entorno. Configurá las credenciales **solo en tu entorno local**; no subas archivos `.env` ni claves al repositorio.
